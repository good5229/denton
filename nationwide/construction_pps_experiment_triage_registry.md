# 건설업·PPS 미추적 실험 산출물 triage registry

생성일: 2026-07-29

## 목적

전국 2015~2025 시군구·업종 GVA 추정 목표에서 건설업은 반복적으로 큰 잔여오차가 남는 업종이다. 최근 `nationwide/`, `reports/`, `scripts/` 아래에는 건설업·PPS·건축HUB·CALS·LH 관련 미추적 실험 파일이 많이 생겼다. 이 문서는 해당 파일들을 무차별적으로 “성능개선 근거”로 포장하지 않기 위해, 어떤 유형을 증거로 채택하고 어떤 유형을 보류해야 하는지 고정한다.

## 커밋/보류 기준

| 파일 유형 | 커밋 판정 | 조건 |
| --- | --- | --- |
| route decision registry, frontier synthesis, guardrail 문서 | 우선 커밋 | 과대주장 방지·후속 작업 기준으로 직접 필요 |
| 수집기·감사 스크립트 | 우선 커밋 | raw data를 재현 가능하게 만들고, 완전월/불완전월 gate를 자동검증할 수 있을 때 |
| 개별 실험 보고서 | 선택 커밋 | 채택/미채택/보류 판정과 금지 해석이 명시되어 있을 때 |
| 단순 후보 성능표 | 보류 | pooled WAPE만 제시하고 최대 APE·10%/20% 초과 셀 guardrail이 없으면 보류 |
| 부분월 PPS 산출물 | 보류 | 완전월 조건을 만족하기 전까지 성능표에 넣지 않음 |
| CSV/JSON 세부 산출물 | Git 제외 | `nationwide/outputs/*.csv`, `nationwide/outputs/*.json`은 재생성 산출물로 `.gitignore` 유지 |

## 반드시 유지할 guardrail

1. 목표연도 시군구 건설업 actual로 혼합비·threshold를 고르지 않는다.
2. 후보는 rolling out-of-year 구조로 평가한다.
3. WAPE만 낮아져도 10% 초과 셀, 20% 초과 셀, 최대 APE 중 하나라도 악화되면 운영 route로 채택하지 않는다.
4. 광역시도 시간경로 개선과 시군구 공간배분 개선을 분리한다.
5. 공공공사 자료는 “공공공사 중심 보조 신호”로만 표기한다.
6. 완전월이 아닌 PPS 자료는 0으로 채우지 않고 성능감사에서 제외한다.

## 금지 문구

- “PPS로 건설업 GVA actual을 관측했다.”
- “공사공고 금액이 전체 건설업 생산액/기성액을 대체한다.”
- “2021년 6월 단독 결과로 PPS route를 채택했다.”
- “건축HUB만으로 전국 시군구 건설업 공간배분이 개선됐다.”
- “건설업 시군구 WAPE 10% 목표를 달성했다.”

## 허용 문구

- “PPS 공사공고는 공공공사 위치·예산의 보조 신호다.”
- “2021년 6월 단독 미세혼합은 guardrail을 통과했으나, 단월 결과이므로 운영 route 채택 근거가 아니다.”
- “2021년 1~6월 누적과 7월 단독에서는 안정적 개선이 재현되지 않아 PPS는 후보로만 유지한다.”
- “건설업은 민간건축, 정비사업, 공공/SOC, 기존 share fallback을 분리한 제한혼합 route가 필요하다.”
- “운영 채택은 2021~2025 완전월 수집 후 rolling out-of-year 검증을 통과할 때로 제한한다.”

## 다음 정리 순서

3. PPS 2021년 8월 이후는 완전월 확보 전까지 보고서에는 rate-limit/부분월 상태만 남긴다.

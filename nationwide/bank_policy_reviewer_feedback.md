# 국책은행 담당자 관점 검토 및 반영 내역

생성일: 2026-07-28

## 검토자 페르소나

- 국책은행·정책금융기관 지역경제/산업분석 담당 10년 이상
- 검토 초점: 집계검증 논리, 정책금융 활용 가능성, 공표시점, 데이터 유출, GVA/GRDP 구분, 전국 경계 해석

## 통과 가능한 점

- `하위단위×업종 추정 → 시도 집계 → 전국 경계 비교` 구조는 지역경제 추정모형의 외부 검증 프레임으로 타당하다.
- 목표분기 시도 actual 배분비를 직접 사용하지 않는 원칙은 적절하다.
- 세종을 제외하지 않고 `세종특별자치시 → 세종시` 단층 하위단위로 처리한 것은 BOK RECI의 17개 광역 기준에 부합한다.
- GVA와 GRDP를 구분하고, 순생산물세·기타산업을 별도 bridge로 처리한 방향은 적절하다.
- 실질 연쇄가격의 비가산성 문제를 해석 제한에 포함해야 한다.

## 반드시 고칠 점과 반영

| 지적 | 반영 |
| --- | --- |
| `1분기+1개월`을 실시간 운용성과처럼 표현하면 안 됨 | 보고서에 “최신 공표 빈티지 기준의 사후 백테스트” 문구 추가 |
| 2023년 시군구 원천 부재 시도 명시 필요 | 부산·대구·울산·강원·충남·경남을 기준값 사용 감사에 표시 |
| `17개 시도`와 `2023년 로컬 시군구 원천 보유`를 구분해야 함 | audit 항목명을 `sigungu_with_2023_local_source`로 변경 |
| 전국 GDP 경계 WAPE 과대해석 금지 | 전국 경계 표 상단에 “외부 일관성 참고지표” 문구 추가 |
| 기타산업·순생산물세가 시도 단위 bridge이므로 시군구 GRDP 순위에 직접 사용 금지 | 출처문서의 해석 제한에 명시 |
| 행정구역 경계 변경은 필수 감사 항목 | 보고서 해석에 군위군·특별자치도 전환 등 경계재정렬 필요 문구 유지 |

## 권장 표현

- 본 검증은 최신 공표 빈티지 기준의 사후 백테스트이며, 공표시점별 원천 빈티지를 완전 재현한 실시간 운용성과로 해석하지 않는다.
- 전국 경계 검증은 17개 시도 추정합의 외부 일관성을 점검하기 위한 참고지표이며, 실질 연쇄가격 계열의 비가산성과 GDP/GRDP 개념 차이로 인해 공식 국민계정 항등식 검증 또는 대체 추계로 볼 수 없다.
- 부산·대구·울산·강원·충남·경남은 2023년 시군구 연간 원천이 부재하여 일부 연도는 직전 예측값 또는 직전연도 시도 공식 업종합 보정을 사용했다.
- 기타산업 및 순생산물세는 시도 단위 bridge로 처리했으므로, 본 산출물은 시도 및 전국 경계 검증용이며 시군구별 총 GRDP 확정치나 순위 산출에는 직접 사용하지 않는다.

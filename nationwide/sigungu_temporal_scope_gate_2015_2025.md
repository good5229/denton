# 2015~2025 시군구 추정 가능범위 게이트

생성일: 2026-07-29

## 1. 목적

전국 목표는 2015~2025년 광역시도·시군구 월/분기 GVA·GRDP 추정과 검증이다. 다만 시군구 단위는 공식 actual 공표 범위가 광역시도 분기 GRDP보다 좁기 때문에, 같은 신뢰도로 전기간을 처리할 수 있는지 별도 게이트가 필요하다.

## 4. 2015~2020 확장 원칙

- 2015~2018 시군구 값은 현재 로컬 공표자료만으로는 직접 actual 기반 검증이 불가능하다.
- 가능한 실험은 `2020년 시군구 구조를 기준으로 과거 시도 총량을 역배분하는 backcast`지만, 이는 공간구조가 과거에도 동일하다는 강한 가정이 들어간다.
- 따라서 대외 성능 근거는 2016~2025 시도 장기검증과 2021~2025 시군구 운영검증으로 분리한다.
- 2015~2018 시군구 backcast를 만들 경우에는 “정책 활용용 과거 비교지표”가 아니라 “장기 패널 연결을 위한 보조 추정치”로 표기한다.

## 6. 결론

현재 전국 목표의 신뢰 가능한 표현은 `2016~2025 시도 장기검증 + 2021~2025 시군구 운영추정·상위집계검증 + 2021~2025 월별 보존형 bridge`다. `2015~2025 전기간 시군구 actual 직접검증`은 현재 공개자료 범위상 완료로 주장하면 안 된다.

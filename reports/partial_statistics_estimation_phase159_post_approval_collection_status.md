# Phase159 신청 완료 후 공개자료 재수집·반영 상태

## 목적

사용자가 추가 활용신청 완료를 알려온 뒤, 현재 로컬 환경에서 실제 호출·재계산 가능한 자료를 다시 점검했다. 예측 대상은 계속 **총부가가치(GVA)** 이며, 아래 자료들은 GVA를 직접 관측한 값이 아니라 업종별 배분·외삽에 쓰는 활동자료다.

## 주의할 점

1. RTMS 전월세 processed 산출물은 샌드박스 DNS 차단으로 한 차례 빈 파일이 되었으나, 네트워크 권한 재실행으로 복구했다.
2. 공공데이터포털 RTMS 전월세 3종은 정상 호출된다. 기존 Phase153의 “오피스텔/단독다가구 403” 메모는 현재 상태에서는 해소됐다.
3. 전월세 자료는 계약월 기준 회고 수집이므로, 속보성 성능표에 그대로 넣으면 자료시점 누출 위험이 있다. 속보성에는 계약월+보수 지연 또는 공식 공표시차 확인 규칙이 필요하다.
4. VWorld 중개업소 전국자료는 무료 자료로 확인됐지만 자동 수집에는 전용 인증키 또는 수동 CSV 다운로드가 여전히 필요하다.

## 다음 필요 조치

전국 공인중개사무소 자료를 자동화하려면 아래 중 하나가 필요하다.

- `VWORLD_API_KEY=...`를 `.env`에 추가
- 또는 VWorld/공공데이터포털에서 `국토교통부_부동산중개업사무소정보` CSV를 직접 내려받아 `data/raw/phase158_broker_vworld/vworld_realestate_broker_office_20260723.csv`에 저장

이 자료가 확보되면 682 부동산 관련 서비스업의 중개·거래서비스 축을 외부 10개 시군구까지 확장 감사할 수 있다.

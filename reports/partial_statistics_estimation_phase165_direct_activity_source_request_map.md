# Phase165 직접 활동자료 수집 우선순위와 API 요청 지도

## 목적

Phase160~164에서 확인한 결론은 명확하다. 외부 peer 구조를 그대로 쓰는 방식은 일부 업종에는 유용하지만, 고양·포항 전체 중분류 GVA 예측오차를 안정적으로 낮추는 주력 방법은 아니다. 다음 개선은 업종별 GVA에 더 가까운 **직접 활동자료**를 붙이는 방식이어야 한다.

이번 문서는 남은 20% 초과 업종을 기준으로, 현재 로컬 보유 자료와 추가로 신청·수집해야 할 무료 공식자료를 구분한다.

## 현재 남은 20% 초과 오차의 큰 덩어리

Phase164 기준 잔여 20% 초과 중분류는 고양 29개, 포항 27개다.

| 지역 | 주요 잔여 상위산업 | 해석 |
| --- | --- | --- |
| 고양시 | J00, ERS, C00, MN0 | 정보통신·환경/개인서비스·제조업·전문서비스가 핵심. 사업체수·종사자수와 GVA 금액구조가 어긋남 |
| 포항시 | MN0, ERS, K00, C00, J00 | 전문서비스·사업지원·환경처리·금융보험·일부 제조업이 핵심. 법인·대형사업장·처리량·계약액 자료 필요 |

## 현재 신청을 요청할 가능성이 높은 항목

아래는 실제로 다음 실험을 진행하려면 사용자가 신청 또는 키 발급을 해주는 편이 좋은 항목이다.

1. `VWORLD_API_KEY`  
   - 목적: 전국 공인중개사무소 자료 자동 수집  
   - 우선순위: 높음  
   - 이유: 682 부동산 관련 서비스업 외부 10개 검증에 직접 필요

2. 조달청_나라장터 사용자정보 서비스  
   - 링크: https://www.data.go.kr/data/15129466/openapi.do?recommendDataYn=Y  
   - 목적: 조달업체 소재지·등록업종·공급물품으로 MN0/F00/사업지원 업종구조 보강  
   - 우선순위: 높음  
   - 기존 공공데이터포털 키로 될 가능성이 높지만 활용신청 상태 확인 필요

3. 조달청_나라장터 업종 및 근거법규서비스  
   - 링크: https://www.data.go.kr/data/15129467/openapi.do  
   - 목적: 조달업체 업종코드 해석 및 KSIC 유사분류 매핑 보조  
   - 우선순위: 중간

4. 보건복지부_건강보험 보험료 및 요양급여의 급여액  
   - 링크: https://www.data.go.kr/data/15098787/openapi.do?recommendDataYn=Y  
   - 목적: Q86 보건업 금액형 활동자료 후보  
   - 우선순위: 중간  
   - 단, 시군구 해상도 확인 전에는 신청 우선순위를 낮게 둔다.

## 즉시 가능한 다음 실험

현재 키와 로컬 자료만으로 바로 가능한 다음 작업은 다음이다.

1. 조달청 사용자정보 API가 현재 키로 바로 열리는지 probe한다.
2. 열리면 고양·포항 조달업체 업종/공급물품/소재지 feature를 만들고, MN0/F00/사업지원 중분류 후보로 screen한다.
3. 제조업은 기존 공장등록·전력·광업제조업 자료를 결합한 block별 보수 라우팅을 다시 점검한다. 다만 외부 peer가 실패했으므로 공장 수만 늘리는 방식은 피한다.
4. 부동산 682는 VWorld 키가 없으면 외부 일반화 검증을 멈추고, 고양·포항 내부 진단으로만 유지한다.

## 판정

Peer prior 계열은 “왜 일괄 보정이 위험한지”를 보여준 검증 장치로 유지한다. 성능 개선의 다음 주력은 조달업체/공장등록생산/처리량/보험·진료비 같은 직접 활동자료다.

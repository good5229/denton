# Phase172 추가 승인 후 API 재시도와 다음 게이트

## 목적

사용자가 잔여 무료 공개자료 활용신청을 완료했다고 알려준 뒤, 고양시·포항시 총부가가치(GVA) 취약 업종 개선에 바로 투입할 수 있는지 재점검했다.

이번 단계의 원칙은 다음과 같다.

1. API 키 값은 출력·저장하지 않는다.
2. 실제 행을 받지 못한 자료는 GVA 성능 개선에 반영하지 않는다.
3. 보조지표는 GVA actual이 아니므로, 하위 추정치를 상위 중분류·대분류 actual로 집계해 검증한다.
4. 포항 항만자료처럼 로컬에 이미 확보된 자료만 제한적으로 다음 모델 후보로 넘긴다.

## 해석

현재 상태는 “신청이 안 됐다”보다 **현재 공공데이터포털 인증키가 해당 gateway 호출에 정상 연결되지 않는 상태**에 가깝다. 동일 키 계열로 과거 수집한 RTMS 대조 API도 Phase168에서 HTTP 403을 반환했기 때문이다.

따라서 조달·보건·폐기물·물류 API를 더 신청하는 것보다 먼저 다음을 확인해야 한다.

1. 공공데이터포털 마이페이지에서 현재 인증키가 활성 상태인지 확인
2. 승인된 각 서비스가 현재 인증키에 연결되어 있는지 확인
3. 일일 트래픽 제한·IP 차단·개발계정 상태 이상 여부 확인
4. 필요 시 공공데이터포털 인증키를 재발급하고 `.env`의 `DATA_GO_KR_DECODING`, `DATA_GO_KR_ENCODING`을 갱신
5. ODCloud 파일 API는 일반 공공데이터포털 키와 별도 인증형일 수 있으므로 해당 페이지의 인증키 요구사항 재확인

## 로컬 자료 기반으로 진행한 다음 후보

공공데이터포털 신규 API는 막혀 있어 모형에 넣지 않았다. 대신 이미 확보된 포항항 품목별 물동량 캐시를 이용해 H00 운수·창고업 중 H50 수상운송업의 보수 규칙을 외부 표본과 함께 점검했다.

관련 산출물:

- `reports/partial_statistics_estimation_phase170_pohang_port_cargo_split_diagnostic.md`
- `reports/partial_statistics_estimation_phase171_h50_floor_external_gate.md`

핵심 결과:

| 후보 | 통합 WAPE | 판정 |
| --- | ---: | --- |
| 기준선 | 32.40% | 기준 |
| H50 존재지역 7% 하한 | 29.24% | 제한적 운영 후보 |
| 모든 지역 7% 하한 | 30.66% | 채택금지 |

포항시는 H00 중분류 WAPE가 8.81%에서 1.28%로 낮아졌지만, 외부 10개 표본 중 H50 행이 존재하는 지역이 영암군·서귀포시 2곳뿐이다. 따라서 이 규칙은 포항 포스터/보고서에 “항만도시형 활동자료 진단”으로 설명할 수는 있으나, 전국 일반 규칙으로 확정하면 안 된다.

## 다음 의사결정

현재 바로 선택 가능한 경로는 두 가지다.

1. **공공데이터포털 키 복구 우선**
   - 신규 승인 자료를 실제 수집해야 조달·보건·폐기물·물류 취약 업종을 추가 개선할 수 있다.
   - 추천: 먼저 공공데이터포털 인증키 재발급 또는 승인 서비스-키 연결 상태 확인.

2. **로컬 보유자료 기반 보수 개선 지속**
   - 포항 H50처럼 이미 있는 자료로만 개선한다.
   - 단, 남은 20% 초과 업종의 상당수는 조달업체·의료기관 가격/진료비·폐기물 처리량·금융 취급액 같은 직접 활동자료 없이는 10~20% 이하로 안정화하기 어렵다.

현재의 엄격한 모델링 판정은 다음과 같다.

> 신규 승인 API는 아직 실제 행이 수집되지 않았으므로 성능 개선에 반영하지 않는다. Phase171의 H50 제한규칙만 “항만도시 추가검증이 필요한 제한적 후보”로 유지한다.

## 3. 아직 막힌 API

### 3.1 조달청 나라장터 계약정보서비스

- 문서: https://www.data.go.kr/data/15129427/openapi.do
- Base URL: `https://apis.data.go.kr/1230000/ao/CntrctInfoService`
- 공사 operation: `getCntrctInfoListCnstwk`, `getCntrctInfoListCnstwkPPSSrch`
- probe 결과:
  - 기존 디코딩키로 입찰공고정보서비스는 정상
  - 동일 키로 계약정보서비스는 403 Forbidden
  - 인코딩키는 401 Unauthorized

추정 원인:

- 공공데이터포털 키 자체는 정상이다.
- 신규 `ao` 계열 서비스의 활용승인 반영이 아직 API Gateway에 적용되지 않았거나, 서비스별 개발계정 권한이 별도로 열리지 않은 상태로 보인다.

필요 조치:

- 마이페이지에서 `조달청_나라장터 계약정보서비스` 개발계정 상태가 `승인`인지 재확인.
- 승인 직후라면 반영 시간을 두고 재시도.
- 계속 403이면 공공데이터포털 문의 시 다음 문구로 문의:
  - “동일 공공데이터포털 인증키로 `조달청_나라장터 입찰공고정보서비스`는 정상이나, `조달청_나라장터 계약정보서비스`의 `getCntrctInfoListCnstwk`가 403 Forbidden을 반환합니다. 활용승인 권한이 API Gateway에 반영되었는지 확인 부탁드립니다.”

### 3.2 조달청 나라장터 발주계획현황서비스

- 문서: https://www.data.go.kr/data/15129462/openapi.do

### 3.3 LH 분양임대공고문 조회 서비스

- 문서: https://www.data.go.kr/data/15058530/openapi.do
- 요청주소: `https://apis.data.go.kr/B552555/lhLeaseNoticeInfo1/lhLeaseNoticeInfo1`
- 필수 파라미터:
  - `ServiceKey`
  - `PG_SZ`
  - `PAGE`
  - `PAN_NT_ST_DT`
  - `CLSG_DT`
- probe 결과:
  - 인코딩키: 401 Unauthorized
  - 디코딩키: 403 Forbidden

추정 원인:

- 서비스별 활용승인 반영 전이거나, LH API의 인증키 파라미터 처리 방식/계정 권한이 별도 상태다.

필요 조치:

- 마이페이지에서 `한국토지주택공사_분양임대공고문 조회 서비스` 승인 상태 확인.
- 계속 실패하면 “정확한 요청주소와 필수 파라미터를 사용했는데 401/403이 반환된다”고 문의.

## 4. 다음 실험 설계

현재 즉시 가능한 route:

1. 서울권 정비사업 블록
   - 대상: 강남구·영등포구·강서구
   - 입력: 단계별 정비사업 수, 건립세대수, 멸실량, 착공일
   - 적용: BuildingHUB와 독립된 `정비사업 단계 점수` 생성

2. 공공/SOC 블록
   - 대상: 도로·하천 공사 영향이 큰 시군구
   - 입력: CALS 계약금액, 계약일, 착공일, 준공일, 공기
   - 적용: 계약금액을 착공~준공 기간에 분산한 공공/SOC 건설활동 점수 생성

3. 기존 BuildingHUB 블록
   - 대상: 민간건축/주거·상업·산업·창고 건축 이벤트
   - 적용: 단독 보정 금지, 이동상한이 있는 보조 신호로만 사용

채택 검증 원칙:

- 과거연도로 가중치를 선택하고 목표연도를 평가한다.
- 시군구별 WAPE, 최대 APE, 10% 초과 셀 수를 모두 보아야 한다.
- 한 지역이라도 대폭 악화되면 단일 route로 채택하지 않고 지역유형 gate를 둔다.

## 5. 현재 판단

자료탐색 우선 접근은 맞았다.

- 서울 정비사업 자료는 서울권 고오차 원인에 직접 닿는다.
- CALS 계약자료는 공공/SOC 건설업 활동자료로 충분히 쓸 수 있다.
- 조달청 계약/발주계획과 LH는 아직 API 권한 확인이 끝나지 않았으므로, 현 단계 실험에는 보류한다.

다음 단계는 `서울 정비사업 + CALS 공공/SOC + BuildingHUB 제한혼합`을 구성해 Phase240의 guardrail을 다시 통과하는지 검증하는 것이다.

# Phase253. 조달청 공사공고 2021년 8월 부분수집 및 429 게이트

생성일: 2026-07-29

## 목적

전국 2015~2025 시군구 건설업 공간배분 개선 후보인 조달청 나라장터 공사공고 자료를 2021년 8월까지 확장 수집하려 했다. 완전월만 성능감사에 투입한다는 기존 원칙을 유지하면서, API 제한 상황에서 부분월이 실험에 섞이지 않도록 수집 게이트를 점검했다.

## 수집 결과

| 항목 | 값 |
| --- | ---: |
| 기간 | 2021년 8월 |
| totalCount | 9,161건 |
| 필요 page | 92 |
| 확보 page | 33 |
| 확보 item | 3,300건 |
| 누락 page | 59 |
| 완전성 | 실패 |
| 성능감사 투입 | 제외 |

확보된 page는 1~21, 36~43, 67~70 중심이다. page 22부터 재시도했으나 `HTTP 429: Too Many Requests`가 즉시 재현되었다. collector 429 즉시중단 보강 후 2026-07-29 후속 page 22 단일 smoke도 다시 `HTTP 429`였으므로 추가 chunk 수집은 중단했다. 현재 시점에서는 8월 완전월 확보를 계속 시도하지 않고, API throttling 해제 후 missing page 단위로 재개하는 것이 안전하다.

## 수집기 보강

`nationwide/collect_pps_construction_robust.py`에 429 안전장치를 추가했다.

- 기본 동작: `HTTP 429` 발생 시 해당 기간 수집 중단
- 재개 방식: 완전성 감사로 missing page를 확인한 뒤 cooldown 이후 작은 page chunk로 재시도
- 예외 옵션: `--continue-on-http-429`를 명시한 경우에만 기존처럼 다음 page로 진행

이 보강은 API 제한 상태에서 빈번한 연속 호출을 피하고, 부분월이 완전월처럼 해석되는 위험을 줄인다.

## 판정

- 2021년 8월은 완전월 조건을 충족하지 못했다.
- 따라서 2021년 8월 PPS 공사공고는 건설업 시군구 공간배분 성능표에 포함하지 않는다.
- 현재 성능감사에 투입 가능한 robust 완전월은 2021년 4~7월이다.
- PPS 공사공고는 계속 보조 후보 신호로만 유지한다. 전체 건설업 GVA actual, 민간공사 activity, 계약액 또는 착공액으로 표현하지 않는다.

## 다음 재개 조건

1. API throttling이 풀린 뒤 2021년 8월 missing page를 작은 chunk로 재시도한다.
2. `expected_pages == cached_pages`, `cached_items == totalCount`, `missing_page_count == 0`이 될 때만 신호 변환을 수행한다.
3. 2021년 8월 완전월 확보 후에도 단월 결과는 운영 route 채택 근거가 아니다. 2021~2025 전체 완전월과 rolling out-of-year 검증이 필요하다.

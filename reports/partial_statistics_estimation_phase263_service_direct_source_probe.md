# Phase263 비건설 서비스업 직접 활동자료 웹 후보 점검

생성시각: 2026-07-29T21:30:00+09:00

## 1. 목적

Phase262에서 확인한 비건설 서비스업 잔여 병목은 월별 시간경로보다 시군구 공간배분 자료 부족에 가깝다. 이번 단계는 운수·창고업, 숙박·음식점업, 정보통신업에 대해 실제 공개 웹에서 무료 수집 가능한 직접 활동자료 후보를 확인하고, 수집 우선순위와 API/다운로드 조건을 정리한다. 이 문서는 수집 후보 레지스트리이며 route 채택이나 성능 개선 주장이 아니다.

## 3. 수집 우선순위

1. **운수·창고업 H00**: 항만도시와 비항만도시를 분리해야 한다. 해수부 항만 물동량은 항만도시 gate에만 쓰고, 국토부 물류창고업등록정보는 전국 시군구 창고 stock·면적 구조 후보로 쓴다.
2. **숙박·음식점업 I00**: LOCALDATA 전체자료 다운로드가 핵심이다. 전체자료로 과거 stock을 만들고, 변동분 API로 이후 증분을 이어 붙이면 공표시점 ledger 구성도 가능하다.
3. **정보통신업 J00**: 방송산업 실태조사는 J60 방송업 정밀화 후보로 먼저 파싱한다. KOBIS는 J59 영화·영상 일부 시간경로일 뿐 J00 전체 공간배분으로 쓰지 않는다.

| 해수부 화물처리실적통계 | 공공데이터포털 활용신청/API key | 사용자가 해수부 관련 승인을 이미 했던 이력이 있으므로 기존 `MOF_API_KEY` 또는 공공데이터포털 key로 재확인 대상 |

| 정보통신업 | 방송업 보고서 파싱값과 KOBIS J59 월별지표를 J00 세부 block 후보로 제한 사용 | J00 전체 actual 또는 중분류 actual이 있는 구간으로 재집계 검증. J59/KOBIS만으로 J00 route 금지 |

## 6. 판정

현재 가장 현실적인 다음 수집은 `물류창고업등록정보`와 `LOCALDATA 음식점·숙박 전체자료`다. 둘 다 시군구 공간구조를 직접 제공할 가능성이 있고, 항만 물동량·방송산업 보고서는 특정 지역·세부업종 gate로 제한해야 한다. 수집 후에는 Phase261과 같은 최소 표본·rolling out-of-year guardrail을 통과해야 하며, 통과 전에는 전국 route로 채택하지 않는다.

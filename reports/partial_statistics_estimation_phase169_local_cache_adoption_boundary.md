# Phase169 로컬 캐시 기반 채택 경계와 다음 실험 기준

## 목적

Phase166~168에서 신규 공공데이터포털 API가 현재 `Forbidden`으로 막힌 것을 확인했다. 따라서 이번 단계에서는 신규 API 행을 실제로 받지 못한 상태에서 성능 개선을 주장하지 않도록, 이미 로컬에 존재하는 자료 중 무엇을 운영형 총부가가치(GVA) 추정에 쓸 수 있고 무엇은 진단 전용인지 다시 고정한다.

판정: 현재 안전한 운영 기준선은 **Phase120/124**다. Phase164는 전체 WAPE를 일부 줄이지만 악화 셀이 남아 있어, 포스터나 제출자료에서는 “향후 개선 후보” 또는 “진단 결과”로만 다뤄야 한다.

## 다음 실험 원칙

1. **총부가가치 예측 성능은 actual을 직접 쓴 사후보정으로 주장하지 않는다.**
2. lower-level 추정은 반드시 상위 실제값으로 집계검증한다.
3. 신규 자료는 실제 행이 수집되고, 공표시점 또는 공개 이벤트 시점이 확인된 뒤에만 속보성 후보로 편입한다.
4. 2도시에서만 맞춘 가중치·gate는 운영 채택이 아니라 진단 전용이다.
5. peer prior는 전체 개선 장치가 아니라, 직접 활동자료가 없을 때의 보조 후보로만 둔다.

## 공공데이터포털 복구 전 가능한 작업

1. **부동산 L00 재검증**
   - Phase149~157 캐시를 사용해 외부 10개 시군구 기준으로 681/682 분리 규칙을 재검증한다.
   - 고양·포항 actual을 gate에 쓰지 않고, 외부 10개에서 통과한 규칙만 두 도시에 적용한다.

2. **포항 H00/C00 물량축 분리**
   - 포항항 월별 품목 물동량은 H50과 철강 관련 제조업을 동시에 설명할 수 있으므로, 수상운송/창고/제조업 물량축을 분리한 후보를 만든다.
   - 중분류 actual 집계검증에서 악화 셀이 생기면 채택하지 않는다.

3. **조달 입찰공고 부분묶음 강화**
   - Phase122 캐시에서 공사/용역/물품 분류와 금액을 더 세분화해 F00/MN0/ERS에만 연결한다.
   - 수요기관 기준 공고는 사업 수행지와 다를 수 있으므로 지역명 텍스트 검증을 필수로 붙인다.

4. **KOBIS의 위치 제한 명확화**
   - J59는 전국 시간패턴 보조에만 사용한다.
   - 고양시 영상산업의 공간·금액 배분에는 기업 매출/제작지원/촬영·상영 지역자료가 없으면 채택하지 않는다.

## 사용자가 확인하면 바로 재시도할 항목

공공데이터포털 gateway가 복구되면 아래 순서로 바로 재수집한다.

1. 조달청_나라장터 사용자정보 서비스: 조달업체 기본정보·업종·공급물품
2. 조달청_나라장터 업종 및 근거법규서비스: 조달업종 코드 해석
3. 건강보험심사평가원_비급여진료비정보조회서비스: Q86 보건업 보조
4. 한국환경공단_폐기물 처리업체 정보 조회 서비스: E38/E39/ERS 공간구조
5. 행정안전부_기타 국제물류주선업 조회서비스: H52 물류 공간구조

## 현재 결론

신규 API는 아직 실제 행을 받지 못했으므로 이번 GVA 모델에 반영하지 않는다. 당장 진행 가능한 개선은 로컬 캐시 기반의 **부동산 외부검증**, **포항항 물동량 기반 H00/C00 분리**, **조달 입찰공고 부분묶음 강화** 세 방향이다.

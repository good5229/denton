# Phase206 제조업 중분류 직접 활동자료 수요 정리

## 목적

Phase200~205에서 제조업 산업생산지수, KICOX 제한수집 종업원, 포항항 품목별 물동량, 시간 안정화 규칙을 검증했다. 이번 문서는 지금까지의 채택/기각 결과를 바탕으로, 고양시·포항시 제조업 중분류/소분류 GVA 오차를 더 줄이기 위해 필요한 직접 활동자료를 정리한다.

## 지금까지의 판정

| 단계 | 자료/모형 | 판정 | 이유 |
|---|---|---|---|
| Phase195~196 | 월간 시도 제조업 산업생산지수 + 시군구 산업용 전력 | 채택 | 제조업 C00 월별 시간경로 개선, 월·분기·연 총량 보존 |
| Phase201 | 산업생산지수 중분류 경계효과 | 역할 제한 | C00 시간경로에는 필수지만 중분류 구성비는 바꾸지 않음 |
| Phase202 | KICOX 제한수집 종업원 혼합 | 기각 | 2023 선택 혼합비가 전년 구성비 1.0으로 수렴 |
| Phase203 | 포항 3년 평균/중앙값 시간 안정화 | 후보 보류 | 2024 사후 성능은 좋지만 2023 기준 사전선택 불가 |
| Phase204 | 포항 사전검증 변동성 게이트 | 기각 | 2024 외부검증에서 기준선보다 악화 |
| Phase205 | 포항항 품목별 물동량 중분류 라우팅 | 기각 | 2023 선택 beta=0, C28은 물동량과 actual 방향 불일치 |

## 포항 제조업 병목

포항 제조업 중분류의 핵심 병목은 C24/C25/C28이다.

| KSIC | 업종명 | 현재 문제 | 필요한 직접 활동자료 |
|---|---|---|---|
| C24 | 1차 금속 제조업 | 포항 제조업 대부분을 차지하며, 전년 구성비 변화가 전체 오차를 좌우 | 포항제철소 또는 포항권 철강 생산·출하·가동 자료, 대형공장 규모, 철강 품목별 물동량 |
| C25 | 금속가공제품 제조업 | C24와 경계가 섞이기 쉬움 | 공장등록 생산품 텍스트, 제조시설면적, 철강산단 입지, 금속가공 키워드 |
| C28 | 전기장비 제조업 | 2022~2023 급등 후 2024 급락. 항만 `전기기기 및 그부품` 물동량은 2024에 오히려 증가 | 업종별 전력, 전기장비 공장 생산품/출하/대형업체 활동, 사업체 단위 변화 |

## 다음 실험 제안

### 1. 공장등록 필지정보 재시도

가장 먼저 KICOX 필지정보 API 승인을 확인해야 한다. 기존 생산정보 API는 회사명 검색형이라 상위 공장 제한수집에는 쓸 수 있었지만, 중분류 구조를 개선하려면 공장면적·필지·입지 정보가 더 중요하다.

필요 조치:

- 공공데이터포털에서 `한국산업단지공단_공장등록필지정보조회서비스` 활용승인 상태 확인
- 승인 후에도 403이면 API 운영기관 문의 또는 데이터포털 마이페이지의 서비스키별 승인 상태 확인

### 2. 포항 C24/C25/C28 전용 블록

운영 가능한 후보식은 다음처럼 구성한다.

`전년 중분류 구성비 × 산업별 직접 활동 성장률`

단, 직접 활동 성장률은 중분류별로 달라야 한다.

- C24: 철강 생산/출하/원료투입/철강 물동량
- C25: 금속가공 공장면적·생산품 키워드·철강산단 입지
- C28: 전기장비 공장 활동, 업종별 전력, 대형업체 변화

### 3. 포스터 반영 기준

포스터에는 실패한 후보를 길게 쓰지 않는다. 대신 다음처럼 정리한다.

- “제조업 월별 총량은 산업생산지수와 전력으로 산정”
- “중분류 구조는 공식 광업제조업조사로 집계검증”
- “포항 C24/C25/C28은 직접 활동자료가 필요한 집중관리 업종”

## 결론

현재까지 엄격 검증을 통과한 것은 제조업 C00 월별 시간배분이다. 중분류 구조오차 개선은 아직 전년 구성비 기준선보다 안정적으로 나은 무료자료 조합을 찾지 못했다.

따라서 다음 성능 개선의 핵심은 새 수식이 아니라 직접 활동자료 수집이다. 특히 포항 C24/C25/C28은 공장면적·대형공장 생산활동·업종별 전력 없이는 10% 안쪽으로 안정적으로 낮추기 어렵다.

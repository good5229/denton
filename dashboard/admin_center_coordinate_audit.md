# 행정 중심 좌표 감사

생성일: 2026-07-28

## 점검 목적

대시보드 요구사항은 지역 검색 후 지도가 도청·시청·군청·구청 등 행정 중심 소재지로 이동하는 것이다. 현재 구현이 이 요구를 충족하는지 별도 감사했다.

## 현재 구현

| 항목 | 현재값 |
| --- | --- |
| 좌표 생성 방식 | 확보된 행정청사 좌표 우선. 현재 246개 전 지역 청사 좌표 적용 |
| 적용 파일 | `dashboard/prepare_dashboard_data.py` |
| 화면 표시 | 모달 상단 `지도 이동 기준: 행정청사 좌표` 또는 `행정구역 도형 대표점` |
| 데이터 필드 | `coordinateBasis`, `coordinateStatus` |
| 판정 | 17개 시도 + 229개 시군구/통합시 전부 청사 좌표 충족 |

## 원천 탐색 결과

| 후보 | 확인 내용 | 판정 |
| --- | --- | --- |
| 로컬 경계자료 | 시도·시군구 경계도형은 보유. 대표점 산출 가능 | 임시 좌표로 사용 가능 |
| 공공데이터포털 인천광역시_시설 정보 현황 | 인천광역시청과 10개 군구청 위도·경도 확인. 원천 CSV 수집 완료 | 인천 11개 지역에 적용 |
| ESRI Korea 관공서(지방자치단체) FeatureServer | 행정안전부 지방자치단체 주소 기반 지오코딩 레이어. 도청·시청·구청·군청 284행 수집 | 인천 직접 원천을 제외한 235개 대시보드 지역에 적용 |

## 운영 판단

1. 현재 대시보드는 검색·모달·데이터 조회 기능이 동작한다.
2. 인천광역시와 10개 군구는 공공데이터포털 원천으로 청사 좌표를 적용했다.
3. 나머지 235개 지역은 ESRI Korea 공개 관공서 레이어의 행정안전부 주소 기반 지오코딩 좌표를 적용했다.
4. 향후 더 최신의 지역별 청사 좌표 원천을 확보하면 `dashboard/data/dashboard_data.json`의 좌표 필드만 교체해도 UI는 그대로 작동한다.

## 확보했으나 자동수집이 막힌 후보

| 자료명 | 링크 | 원인/다음 조치 |
| --- | --- | --- |
| 경기도 청사및출장소 현황 | `https://data.gg.go.kr/portal/data/sheet/downloadSheetData.do?downloadType=C&infId=4S17FIR05U0L2SOW82B712842838&infSeq=1` | 자동접속 시 보안정책 차단 HTML 반환. 브라우저 수동 다운로드 또는 경기데이터드림 API 호출명을 확인해 재수집 |

경기도 CSV를 확보하면 아래 경로에 저장한다.

```text
data/raw/admin_center_coordinates/gyeonggi_office_branch_15057551.csv
```

`dashboard/prepare_dashboard_data.py`는 이 파일이 존재할 경우 `도청`, `시청`, `군청` 행을 자동으로 읽어 경기도 및 경기도 시군 좌표를 청사 기준으로 교체한다.

## 사용권·기준일 주의

ESRI/MOIS 좌표는 공개 조회 가능한 FeatureServer에서 수집했으나, 원천 메타데이터의 사용권 표기는 `All rights reserved by Korean Ministry of Interior and Safety`다. 외부 재배포·상업적 이용 가능 범위는 원천 사용조건을 별도 확인해야 한다. 수집 CSV의 원자료 기준일은 2016.12, 서비스 갱신 표기는 2025.02다.

## 교체 기준

청사 좌표 원천을 채택하려면 다음 조건을 충족해야 한다.

| 조건 | 이유 |
| --- | --- |
| 전국 17개 시도와 229개 시군구/통합시를 포괄 | 특정 지역 누락 시 검색 이동 품질이 불균등해짐 |
| 위도·경도 또는 안정적 주소 포함 | 지도 이동에 직접 필요 |
| 무료 공공자료 또는 사용 허가가 명확한 자료 | 프로젝트 데이터 원칙 유지 |
| 갱신일·출처 기록 가능 | 추후 일반화 분석과 재현성 확보 |
